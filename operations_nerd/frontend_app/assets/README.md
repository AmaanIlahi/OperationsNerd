# Frontend asset provenance

The unified OperationsNerd interface adapts the existing LogisticsNerd visual design from `logisticsnerd/src/styles.css`, `src/business.css`, `src/purchasing.css` and `src/demo-navigation.css`. The colors, DM Sans typography, panel treatments and form/navigation spacing follow that source. Application code and API integration remain OperationsNerd-native.

- `dm-sans-latin-wght-normal.woff2`: unmodified local copy from the existing LogisticsNerd dependency `@fontsource-variable/dm-sans` version 5.3.0, `files/dm-sans-latin-wght-normal.woff2`. Copyright 2014 The DM Sans Project Authors. Distributed under the SIL Open Font License 1.1; full license is in `DM-Sans-OFL.txt`.
- `favicon.svg`: unmodified copy of the user's LogisticsNerd `public/favicon.svg`.

Fonts and icons are served locally. No third-party font service is required.
